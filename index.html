Under the hood

What it's bad at

Making things up

Sounds confident when wrong. Plausible is not the same as true.

Counting and exact maths

It sees tokens, not letters or digits.

Recent events

Knowledge stops at its training cutoff.

Knowing what it doesn't know

Check its work. Give it context. Ask for sources.

Run it on your own laptop

No subscription needed

Run it locally

Why run a model locally?

1

Free

No subscription, no API bill

2

Private

Your data stays on your machine

3

Offline

Works without internet

4

Hackable

A local API you can build on

Trade-off: smaller models, less smart than the big cloud ones. Needs RAM.

Run it locally

Install Ollama

macOS / Windows

Download from ollama.com/download

Linux

curl -fsSL https://ollama.com/install.sh | sh

Then

# download a small model
ollama pull llama3.2:3b

# chat with it
ollama run llama3.2:3b

Slow Wi-Fi or 8 GB RAM? Use llama3.2:1b or gemma3:1b.

Run it locally

Which model fits my laptop?

Your RAMTryDownload (approx.)
8 GBllama3.2:1b · gemma3:1b · llama3.2:3b0.8 – 2 GB
16 GBllama3.1:8b · qwen2.5:7b~5 GB
32 GB+qwen2.5:14b~9 GB

Quantization: weights stored in fewer bits. Much smaller, slightly less accurate.

More models: ollama.com/library

Run it locally

Cheat sheet

ollama list        # models you have
ollama ps          # models loaded now
ollama show llama3.2:3b
ollama rm llama3.2:3b
# inside ollama run
/set parameter temperature 0
/set system "Answer in one sentence."
/clear
/bye

API on http://localhost:11434
